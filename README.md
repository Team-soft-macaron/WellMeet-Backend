## 1. 프로젝트 개요

### 1-1. 프로젝트 소개

**"귀한 손님을 위한 완벽한 한 끼, AI가 찾아드립니다"**

특별한 손님과의 소중한 시간을 위해 AI가 상황별 최적의 맛집을 추천하고, 예약부터 특별 서비스까지 원스톱으로 제공하는 프리미엄 다이닝 플랫폼입니다.
